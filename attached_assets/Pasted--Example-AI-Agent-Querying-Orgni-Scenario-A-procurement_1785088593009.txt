### Example: AI Agent Querying Orgni

**Scenario:** A procurement agent needs to approve a supplier payment.

#### 1. Agent sends a query to Orgni

```json
POST /v1/context/query

{
  "agent_id": "procurement-agent",
  "objective": "Determine whether supplier invoice INV-2048 can be approved",
  "entities": {
    "invoice_id": "INV-2048",
    "supplier_id": "SUP-019"
  },
  "requested_context": [
    "approval_rules",
    "supplier_status",
    "purchase_order",
    "proof_of_delivery",
    "payment_history",
    "known_exceptions"
  ]
}
```

#### 2. Orgni returns operational context

```json
{
  "query_id": "qry_82f1",
  "decision_status": "blocked",
  "confidence": 0.96,
  "context": {
    "invoice": {
      "invoice_id": "INV-2048",
      "amount": 48500,
      "currency": "ZAR",
      "supplier": "Mokoena Industrial Supplies"
    },
    "purchase_order": {
      "po_number": "PO-8821",
      "amount": 48500,
      "status": "approved"
    },
    "supplier": {
      "status": "active",
      "compliance_status": "valid",
      "bank_details_changed": true,
      "bank_details_changed_at": "2026-07-24T09:32:00Z"
    },
    "proof_of_delivery": {
      "status": "confirmed",
      "confirmed_by": "warehouse-manager"
    },
    "approval_rule": {
      "rule_id": "FIN-APR-07",
      "description": "Payments above R25,000 with recently changed banking details require finance verification.",
      "required_approver": "finance-manager"
    },
    "exceptions": [
      {
        "type": "banking_details_change",

      }
    ]

    "action": "request_finance_verification",

```

#### 3. The agent acts using Orgni’s response

```json
{
  "action": "create_approval_request",
  "assigned_to": "finance-manager",
  "invoice_id": "INV-2048",
  "reason": "Banking details require verification before payment.",
  "orgni_query_id": "qry_82f1"
}
```

### What Orgni is doing

The AI agent does not search through every invoice, policy, email and workflow itself. It asks Orgni for the relevant operational context.

Orgni returns:

* what happened;
* which business rules apply;
* who has authority;
* what is blocking the process;
* what evidence supports the answer;
* what should happen next.

In simple terms:

```text
AI Agent: What should I do?

Orgni: Here is the organisation’s current state, applicable rule,
supporting evidence, responsible person and permitted next action.
```
